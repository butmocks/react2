# Мини 2048 (карты) — отчёт

## Что сделано
- Статическое веб-приложение без сборщика: `apps/mini-2048/`
- Игровая логика 2048: поле 4×4, объединение одинаковых карт, спавн 2/4, конец игры при отсутствии ходов
- Прогресс до 2048 (процент по максимальной карте)
- Достижения (несколько штук) + бейджи
- Автосохранение в `localStorage` + лучший счёт
- Управление: стрелки / WASD / свайпы

## Как запустить локально
Из корня репозитория:

```bash
python3 -m http.server 4173 --directory /workspace/apps/mini-2048
```

Открыть в браузере:
- `http://localhost:4173/`

Если нужна другая команда (например Node):

```bash
npx --yes http-server /workspace/apps/mini-2048 -p 4173 -c-1
```
